Install alpha

MOR-1 is in alpha. The installer will be here with the first firmware build, and test beta downloads are coming soon. Until then, try it in the browser: the same code the FM-1 will run.

When it's ready, installing works from Chrome or Edge with the FM-1 connected by a USB data cable, with nothing to install on the computer, and the same page can put M-VAVE's own firmware back.
