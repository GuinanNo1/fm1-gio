**GIO-1 0.3.1-beta: GIO-1 moves to beta.**

GIO-1 turns the M-VAVE FM-1 into a generative electronic disco machine. Try it in the browser first:
https://guinanno1.github.io/fm1-gio/emu/

GIO-1 is now a beta: 0.3.1-alpha has been installed on three FM-1s so far with no major issues reported. This release
also fixes the link for the FM-1 Screen Reader. Nothing in the music or the controls has changed.

> [!WARNING]
> **Install with caution.** GIO-1 is unofficial, independent firmware, not made, endorsed or supported by M-VAVE. It
> is a beta: no major issues have been reported so far, but it has been tried on only a few FM-1s, and any
> unofficial firmware can in rare cases leave an FM-1 that won't start. You install it at your own risk; the author
> accepts no responsibility for any damage to your device. Please report what happens in the Issues.

> [!NOTE]
> **Tested so far:** three FM-1s, with no major issues reported. The first two have m-bootloader installed too, and
> on those, other firmware was installed over GIO-1 and GIO-1 put back again.

> [!NOTE]
> **The safety nets** (from fm1-base, unchanged):
> - **A crash** shows a red CRASH screen, and the FM-1 restarts.
> - **Two failed starts in a row:** SAFE MODE, with no sound and USB still on, so you can install again or put
>   M-VAVE's firmware back.
> - **If safe mode fails too:** the chip's own update mode, from which the FM-1 rescue tool
>   (`base/bsp/tools/fm1_rescue.sh`, macOS) puts M-VAVE's stock firmware back.
> - **Update mode by hand:** hold REC while switching the FM-1 on, until the screen says UPDATE MODE. With m-bootloader installed, the screen
>   stays black instead: that is its update mode (the same chip's mode). Switch off and on again to leave it.
> - **Back to stock:** the installer's "Back to the official firmware", with M-VAVE's own `FM-1.fwsc`.

**Changes since 0.3.1-alpha:**
- **The FM-1 Screen Reader** ([fm1-reader](https://charlesvestal.github.io/fm1-reader/)) now finds GIO-1's words. The
  FM-1 used to send the reader a placeholder address, so the reader read the screen as plain text without GIO-1's
  own words; it now points at GIO-1's site. Thanks to the reader's author for the report.
- Its status and the warnings: beta, no major issues so far.

Your saved songs are kept when you install it over 0.3.1-alpha (or earlier).

**Package:** `gio-0.3.1-beta.fwsc` (its identity `FM-1_58` and the version), built and tested on GitHub by the shared FM-1 builder, with signed build provenance (see BUILDING.md to verify it).

GIO-1 is a fork of AMB-1 by Charles Vestal, built on fm1-base and felucca-bsp (Hügelton Instruments). MPL-2.0.
