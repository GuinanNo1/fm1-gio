**GIO-1 0.3.2-beta: newer FM-1s, M-UPGRADE 3.11 and safer installs.**

GIO-1 turns the M-VAVE FM-1 into a generative electronic disco machine. Try it in the browser first:
https://guinanno1.github.io/fm1-gio/emu/

This release brings GIO-1's platform (fm1-base) up to date. It matters most if your FM-1 is one of the newer units, or
if you want to go back to M-VAVE's firmware with M-UPGRADE. Nothing in the music or the controls has changed.

> [!WARNING]
> **Install with caution.** GIO-1 is unofficial, independent firmware, not made, endorsed or supported by M-VAVE. It
> is a beta: no major issues have been reported so far, but it has been tried on only a few FM-1s, and any
> unofficial firmware can in rare cases leave an FM-1 that won't start. You install it at your own risk; the author
> accepts no responsibility for any damage to your device. Please report what happens in the Issues.

> [!NOTE]
> **Tested so far:** this beta has been tested on only **two FM-1s**, both with the **original flash chip**. It
> installed and ran with no issues on both, one of them from M-VAVE's stock firmware, and m-bootloader was installed
> with it on both. It has **not** yet been tried on
> one of the newer FM-1s with the UC25HQ80 flash chip, the units this release fixes saving on: if you have one, please
> report how it goes in the Issues. (0.3.1 was installed on three FM-1s with no major issues reported.)

> [!NOTE]
> **The safety nets** (from fm1-base):
> - **A crash** shows a red CRASH screen, and the FM-1 restarts.
> - **Two failed starts in a row:** SAFE MODE, with no sound and USB still on, so you can install again or put
>   M-VAVE's firmware back.
> - **If safe mode fails too:** the chip's own update mode, from which the FM-1 rescue tool
>   (`base/bsp/tools/fm1_rescue.sh`, macOS or Linux) puts M-VAVE's stock firmware back. It now works on the newer
>   FM-1s too, with M-VAVE's V15 or V16.
> - **Update mode by hand:** hold REC while switching the FM-1 on, until the screen says UPDATE MODE. With m-bootloader installed, the screen
>   stays black instead: that is its update mode (the same chip's mode). Switch off and on again to leave it.
> - **Back to stock:** the installer's "Back to the official firmware", with M-VAVE's own `FM-1.fwsc`, or M-VAVE's
>   M-UPGRADE 3.11.

**Changes since 0.3.1-beta:**
- **Newer FM-1s.** Units sold since autumn 2026 (many from AliExpress) have a different flash chip, the UC25HQ80.
  On those, 0.3.1 couldn't save songs (SAVE failed and nothing was kept after switching off), ignored backup and
  restore, and couldn't install another firmware over itself. All of these now work on both chips.
- **M-UPGRADE 3.11** (M-VAVE's current updater) finds GIO-1. It didn't recognise 0.3.1's identity, so it couldn't
  be used to go back to the stock firmware.
- **Recording over USB:** no more dropouts when recording into iOS's Camera, and no more warble when the computer
  resamples the FM-1's audio.
- **The installer and backup pages:** Restore and choosing a backup file now work on iPhone and iPad; M-VAVE's V16
  stock firmware is recognised beside V15; the installer refuses another firmware's package when the FM-1 is in
  M-VAVE's own loader; and installs are faster on FM-1s that support it.
- **The Mirror page** shows the dimly lit buttons and keys too, as the browser emulator does.
- Smaller fixes in the platform's interrupt handling and USB message handling.

Your saved songs are kept when you install it over 0.3.1-beta (or earlier).

**Package:** `gio-0.3.2-beta.fwsc` (its identity `FM-1_58` and the version), built and tested on GitHub by the shared FM-1 builder, with signed build provenance (see BUILDING.md to verify it).
